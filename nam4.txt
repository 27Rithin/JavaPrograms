Case Study Questions & Answers
🔷 Case Study 1: CREATE TABLE
Q: Create a table for student information.

✅ Answer:

sql
Copy code

CREATE TABLE Students (
  ID INT PRIMARY KEY,
  Name VARCHAR(50),
  Age INT,
  Email VARCHAR(100)
);


🔷 Case Study 2: INSERT Values
Q: Insert 3 records into the Students table.

✅ Answer:
INSERT INTO Students (ID, Name, Age, Email)
VALUES
  (1, 'Ram', 20, 'ram@gmail.com'),
  (2, 'Sita', 21, 'sita@gmail.com'),
  (3, 'Laxman', 22, 'laxman@gmail.com');

🔷 Case Study 3: UPDATE
Q: Update Sita’s age to 23.

✅ Answer:
UPDATE Students
SET Age = 23
WHERE Name = 'Sita';

🔷 Case Study 4: DELETE
Q: Delete record of Laxman.

✅ Answer:
DELETE FROM Students
WHERE Name = 'Laxman';
 
🔷 Case Study 5: SELECT
Q: Show all student records.

✅ Answer:
SELECT * FROM Students;

🔷 Case Study 6: ALTER TABLE
Q: Add a column Gender to the Students table.

✅ Answer:

ALTER TABLE Students
ADD Gender VARCHAR(10);

🔷 Case Study 7: DROP TABLE
Q: Delete the entire Students table.

✅ Answer:
DROP TABLE Students;
