DDL Commands with Syntax & Examples
👉 CREATE
Syntax:

CREATE TABLE table_name (
  column1 datatype,
  column2 datatype,
  ...
);


CREATE TABLE Students (
  ID INT,
  Name VARCHAR(50),
  Age INT
);
 


Used to modify structure (e.g., add column).

ALTER TABLE Students ADD Email VARCHAR(100);



Deletes the entire table.
DROP TABLE Students;
